# Raízes Educação Infantil 🌱✨

Este é o repositório do site institucional da escola **Raízes Educação Infantil**, desenvolvido pela empresa júnior **PotiCode**. O projeto consiste em uma plataforma web moderna, rápida e totalmente responsiva, criada para apresentar a proposta pedagógica da escola e facilitar a captação de novas matrículas.

---

## 🏫 Sobre a Raízes Educação Infantil

A **Raízes** é uma escola de educação infantil voltada para o desenvolvimento integral de crianças de **2 a 6 anos**. Utilizando uma metodologia lúdica, a instituição une o aprendizado ao brincar, oferecendo um ambiente acolhedor, seguro e estimulante.

### 🎨 Identidade Visual e Estilo
O design do site reflete a energia da escola através de uma interface alegre e acolhedora, utilizando uma paleta de cores vibrantes baseada em:
* 🟡 **Amarelo** (Energia e criatividade)
* 🟢 **Verde** (Crescimento e natureza)
* 🔵 **Azul** (Confiança e segurança)

---

## 🗺️ Estrutura do Site

O site foi estruturado de forma simples e intuitiva, dividido em 3 páginas principais:

1. **Página 1 – A Escola (`/`):** Apresentação detalhada da proposta pedagógica, valores fundamentais da instituição e tour visual pela estrutura física.
2. **Página 2 – Turmas e Rotina (`/turmas`):** Informações sobre as faixas etárias atendidas, horários de funcionamento e a dinâmica das atividades diárias/lúdicas.
3. **Página 3 – Quero Matricular (`/matricula`):** Página de conversão contendo um formulário interativo para captação de leads com os seguintes campos:
   * Nome do responsável
   * E-mail
   * Telefone (WhatsApp)
   * Idade da criança

---

## 🛠️ Tecnologias Utilizadas

Para garantir a melhor performance, SEO de alta qualidade e uma manutenção simplificada, escolhemos a seguinte stack tecnológica:

* [**Astro**](https://astro.build/) - Framework web focado em velocidade (geração estática - SSG), ideal para sites institucionais orientados a conteúdo.
* [**Tailwind CSS**](https://tailwindcss.com/) - Framework utilitário de CSS para estilização rápida, moderna e consistente com a identidade visual da escola.
* [**HTML5 & JavaScript (ES6+)**](https://developer.mozilla.org/pt-BR/) - Para a estrutura semântica e interações dinâmicas nativas (como validação de formulários), sem peso desnecessário de frameworks pesados de JS no cliente.
